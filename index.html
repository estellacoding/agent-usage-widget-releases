  • 百分比和進度條都代表「還能用多少」，不會混用已使用與剩餘額度。The number and the track always mean remaining — never a mix of used and remaining.

隱私Privacy

常見問題Boundaries

下載前，你可能想先知道。Clear before you install.

這是 Anthropic 或 OpenAI 的官方工具嗎？Is this an official Anthropic or OpenAI tool?

不是。這是獨立開發的非官方工具。Claude 或 OpenAI 若調整登入方式或用量端點，小工具可能暫時讀不到資料，或與官方頁面顯示不同；請以官方頁面為準。No. It is an unofficial, best-effort integration. Endpoint, login, or service changes can cause failures or differences; the provider’s own pages are authoritative.

「即時」資料是什麼意思？Does “live” mean officially guaranteed accuracy?

代表最近一次向服務查詢額度時成功取得資料，不代表官方保證數字完全準確。若畫面顯示「快取」或「已過期」，也會附上資料時間；無法取得時則會說明是登入、權限或服務連線問題。No. Live only means the latest request to that service endpoint succeeded. Cached and stale show the data’s age, and unavailable explains a missing sign-in, a denied permission, or a service failure.

為什麼 macOS 會詢問「Claude Safe Storage」權限？Why does the Claude Safe Storage prompt appear?

為了取得 Claude 即時額度，小工具會沿用你在 Claude Desktop 的登入狀態，因此 macOS 會詢問是否允許存取。「允許」只同意這一次；「永遠允許」可避免每分鐘更新時重複詢問。你也可以在設定中完全關閉這項權限。Claude’s live quota reuses the existing Claude Desktop session. Allow grants one access; Always Allow avoids a repeat prompt on every minute’s refresh. You can also disable Claude Keychain access on its own.

如何完整移除？How do I remove everything?

先到設定關閉「登入時啟動」，再從桌面卡片按右鍵並選擇結束。接著刪除「應用程式」中的 App、本機 Agent Skill 和非敏感快取；若使用 PKG 安裝，也可以一併移除安裝收據。Turn off launch at login in Settings, quit from the card’s context menu, then remove the app, local Skill, and non-sensitive cache. A PKG install can also have its receipt forgotten.
