  • 大數字與進度軌一律是剩餘，不會一半已用、一半剩餘。The number and the track always mean remaining — never a mix of used and remaining.

重要邊界Boundaries

安裝前先說清楚。Clear before you install.

這是 Anthropic 或 OpenAI 的官方工具嗎？Is this an official Anthropic or OpenAI tool?

不是。這是非官方的 best-effort 整合；端點、登入或服務調整都可能讓讀取失敗或與服務頁面不同，請以服務自己的頁面為準。No. It is an unofficial, best-effort integration. Endpoint, login, or service changes can cause failures or differences; the provider’s own pages are authoritative.

「即時」代表官方保證準確嗎？Does “live” mean officially guaranteed accuracy?

不代表。即時只表示最近一次對該服務端點的請求成功；快取與過期會顯示資料年齡，無資料會說明缺少登入、權限或服務錯誤。No. Live only means the latest request to that service endpoint succeeded. Cached and stale show the data’s age, and unavailable explains a missing sign-in, a denied permission, or a service failure.

為什麼會跳出 Claude Safe Storage 提示？Why does the Claude Safe Storage prompt appear?

Claude 的即時額度需要沿用 Claude Desktop 的既有 session。「允許」只授權一次，「永遠允許」可避免每分鐘刷新重複詢問；也可以單獨停用 Claude Keychain 存取。Claude’s live quota reuses the existing Claude Desktop session. Allow grants one access; Always Allow avoids a repeat prompt on every minute’s refresh. You can also disable Claude Keychain access on its own.

怎麼完整移除？How do I remove everything?

在桌面卡右鍵選單停用開機啟動並結束，移除 Applications 裡的 App，再移除本機 Skill 與非敏感快取。用 PKG 安裝的話也可以一併忘記 receipt。From the card’s context menu, disable launch at login and quit, remove the app from Applications, then remove the local Skill and the non-sensitive cache. A PKG install can also have its receipt forgotten.
