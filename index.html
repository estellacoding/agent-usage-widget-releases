第一次開啟Opening it the first time

macOS 會先擋一次，這是預期的macOS blocks it once, and that is expected

這個 app 沒有付費的 Apple 開發者公證，所以第一次開啟會被 Gatekeeper 攔下。 以下三步只需做一次。 This app has no paid Apple Developer notarization, so Gatekeeper stops the first launch. These three steps are needed once.

  1. 安裝Install

    開啟下載的 .dmg，把 AgentUsageWidget 拖到 Applications。 用 .pkg 的話雙擊照指示走完即可。 Open the .dmg and drag AgentUsageWidget into Applications. With the .pkg, double-click and follow the installer.

  2. 雙擊，然後被擋下Double-click, and get blocked

    會看到「Apple 無法驗證此 App 是否含有惡意軟體」。關掉對話框就好。 You will see "Apple could not verify … is free of malware". Dismiss it.

  3. 系統設定 → 隱私權與安全性 → 仍要打開 System Settings → Privacy & Security → Open Anyway

    往下捲到剛才被阻擋的訊息，按「仍要打開」並確認。之後就能正常雙擊啟動。 Scroll to the message about the blocked app, click Open Anyway and confirm. Double-clicking works from then on.

macOS 15 之後，Apple 已移除「右鍵 → 打開」這條捷徑，未公證的 app 只能走系統設定。 習慣終端機的話，xattr -dr com.apple.quarantine /Applications/AgentUsageWidget.app 可以取代第 2–3 步。 macOS 15 removed the old right-click → Open shortcut for unnotarized apps; System Settings is now the only route. If you prefer a terminal, xattr -dr com.apple.quarantine /Applications/AgentUsageWidget.app replaces steps 2–3.

登入材料只在記憶體中用來呼叫該服務自己的官方端點，不寫入磁碟、不輸出、不傳給任何第三方。 本機快取只存百分比與時間戳。沒有遙測、沒有分析、沒有遠端後台。 Login material is used in memory only, to call each service's own endpoint. It is never written to disk, printed, or sent anywhere else. The local cache holds nothing but percentages and timestamps. No telemetry, no analytics, no backend.

沒有可用登入時才退回本機資料，且畫面會標註資料年齡，不會把舊值當成即時值。 Without a usable login it falls back to local data and labels how old that data is, rather than presenting a stale number as live.

遇到問題If something looks wrong

Claude 三列都顯示 --%All three Claude rows show --%

通常是沒有登入 Claude Desktop，或 Keychain 提示被拒。在終端機執行 /Applications/AgentUsageWidget.app/Contents/MacOS/AgentUsageWidget --status 可以看到它解析到的路徑與設定。 Usually Claude Desktop is not signed in, or the Keychain prompt was declined. Run /Applications/AgentUsageWidget.app/Contents/MacOS/AgentUsageWidget --status to see the paths and settings it resolved.

macOS 一直跳出 Claude Safe Storage 的 Keychain 提示 macOS keeps asking for Claude Safe Storage

「允許」只授權一次，每分鐘刷新時會再問；選「永遠允許」可以不再跳出， 代價是本機的 security 指令之後可讀取該項目。自用機器通常可接受， 共用機器建議選「允許」。 "Allow" grants one refresh, so it asks again a minute later. "Always Allow" stops the prompts, at the cost of letting the local security command read that item later. Fine on a personal machine; prefer "Allow" on a shared one.

表示沒有可用的 auth.json，正在使用 Codex CLI 留下的舊紀錄。 重新登入 Codex 後刷新即可。 That means there is no usable auth.json, so it is reading old records left by the Codex CLI. Sign in to Codex again and refresh.
